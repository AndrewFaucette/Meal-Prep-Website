# Meal Prep Application

## Team Members

Andrew Faucette, Cody Winter, Garyeong Bae, Paige Sullivan

## Software Description

This is a Meal Plan Budget Tracker that can allow students to build a budget and come up with a meal plan for the week. This tracker includes the amount of calorie intake, how much certain ingredients will cost, and even some recipes that students, or others, can post online for other students. We want the students to live within their means and not have to worry too much about what to eat for the week, despite how stressful it can be to find a good meal.
